# CJM заведения

Диаграмма описывает путь заведения от публикации меню до завершения
обработки заказа.

```mermaid
flowchart TD
    A["Заведение подключается к Авито.Кухне"] --> B["Передаёт своё меню"]
    B --> C["Основной сервис сохраняет меню"]
    C --> D["Заведение обновляет цены и доступность блюд"]
    D --> E["Заведение запрашивает новые заказы"]
    E --> F{"Есть новые заказы?"}

    F -- "Нет" --> G["Ожидает перед следующим запросом"]
    G --> E

    F -- "Да" --> H["Получает заказ со статусом created"]
    H --> I{"Заведение может выполнить заказ?"}

    I -- "Нет" --> J["Переводит заказ в статус rejected"]
    I -- "Да" --> K["Переводит заказ в статус accepted"]
    K --> L["Начинает приготовление"]
    L --> M["Переводит заказ в статус preparing"]
    M --> N["Завершает приготовление"]
    N --> O["Переводит заказ в статус ready"]
    O --> P["Выдаёт заказ, статус delivered"]
```

## Какие могут быть проблемы

- сервис заведения временно не может обратиться к основному сервису;
- блюдо закончилось после последнего обновления меню;
- один заказ был получен заведением повторно;
- заведение пытается выполнить недопустимый переход статуса;
- пользователь отменил заказ раньше, чем заведение успело его принять.
