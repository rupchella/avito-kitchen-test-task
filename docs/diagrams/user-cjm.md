# CJM пользователя

Диаграмма описывает путь пользователя от выбора заведения до получения
результата заказа.

```mermaid
flowchart TD
    A["Пользователь открывает Авито.Кухню"] --> B["Просматривает список заведений"]
    B --> C["Выбирает заведение"]
    C --> D["Открывает меню"]
    D --> E["Выбирает блюда и их количество"]
    E --> F["Отправляет заказ"]
    F --> G{"Все блюда существуют и доступны?"}

    G -- "Нет" --> H["Пользователь получает сообщение об ошибке"]
    H --> D

    G -- "Да" --> I["Сервис рассчитывает стоимость"]
    I --> J["Заказ создаётся со статусом created"]
    J --> K["Пользователь отслеживает статус"]
    K --> L{"Ресторан принял заказ?"}

    L -- "Нет" --> M["Заказ получает статус rejected"]
    L -- "Да" --> N["Заказ получает статус accepted"]
    N --> O["Ресторан готовит заказ"]
    O --> P["Заказ получает статус ready"]
```

## Какие могут быть проблемы

- выбранное блюдо стало недоступно перед оформлением;
- ресторан отклонил заказ;
- пользователь повторно отправил запрос на создание заказа;
- цена блюда изменилась после создания заказа.
