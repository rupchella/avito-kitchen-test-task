# CJM пользователя

Диаграмма описывает путь пользователя от поиска блюда до получения
результата заказа.

```mermaid
flowchart TD
    A["Пользователь открывает Авито.Кухню"] --> B{"Знает, чего хочет?"}

    B -- "Нет" --> C["Просматривает список заведений"]
    C --> D["Выбирает заведение"]
    D --> E["Открывает меню"]

    B -- "Да" --> S["Ищет блюдо по названию по всей площадке"]
    S --> T{"Что-то нашлось?"}
    T -- "Нет" --> C
    T -- "Да" --> U["Видит блюдо вместе с заведением"]
    U --> E

    E --> E2["Выбирает блюда и их количество"]
    E2 --> F["Отправляет заказ"]
    F --> G{"Все блюда существуют и доступны?"}

    G -- "Нет" --> H["Пользователь получает сообщение об ошибке"]
    H --> E

    G -- "Да" --> I["Сервис рассчитывает стоимость"]
    I --> J["Заказ создаётся со статусом created"]
    J --> K["Пользователь отслеживает статус"]
    K --> Q{"Передумал, пока заказ не принят?"}

    Q -- "Да" --> R["Отменяет заказ, статус cancelled"]

    Q -- "Нет" --> L{"Ресторан принял заказ?"}

    L -- "Нет" --> M["Заказ получает статус rejected"]
    L -- "Да" --> N["Заказ получает статус accepted"]
    N --> O["Ресторан готовит заказ"]
    O --> P["Заказ получает статус ready"]
    P --> V["Заказ выдан, статус delivered"]
```

## Какие могут быть проблемы

- пользователь не знает, в каком заведении искать нужное блюдо;
- выбранное блюдо стало недоступно перед оформлением;
- пользователь передумал уже после того, как заведение приняло заказ;
- ресторан отклонил заказ;
- пользователь повторно отправил запрос на создание заказа;
- цена блюда изменилась после создания заказа.
